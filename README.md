# 부동산 계산기 10종

GitHub Pages용 순수 HTML/CSS/JavaScript 프로젝트입니다.

포함: 주택 매매 자금계획, 취득세, 전세자금, LTV, DTI, DSR, 중개보수, 재산세, 청약 자금계획, 월 상환금.

## 업로드
1. GitHub 새 저장소 생성
2. 이 폴더의 `index.html`, `style.css`, `script.js` 업로드
3. Settings → Pages → Deploy from a branch → `main` / `/root`
4. 생성된 Pages 주소에서 확인

※ 세금·대출 계산은 참고용 단순 계산이며 실제 적용 시 최신 법령·상품 조건을 반영해야 합니다.
