# 부동산 계산기 10종 v2

GitHub Pages용 부동산 금융 계산기입니다.

## 개선사항
- 금액 입력란에 `만원` 단위 표시
- 입력 숫자 자동 콤마 표시
- 모바일/태블릿 반응형 개선
- 계산기 카드를 HTML에 직접 구성하여 JS 오류가 있어도 화면이 비어 있지 않도록 개선
- 모달형 계산 화면 개선
- 매매자금, 전세자금, LTV, DTI, DSR, 중개보수, 재산세, 청약자금, 월상환 계산 제공

## 업로드
`index.html`, `style.css`, `script.js`를 GitHub 저장소의 기존 파일과 교체하면 됩니다.

## 주의
취득세·재산세·중개보수·LTV·DSR 등은 실제 적용 시 개인의 주택 수, 지역, 거래유형, 금융기관 심사 및 당시 법령에 따라 달라질 수 있습니다. 본 계산기는 참고용입니다.
